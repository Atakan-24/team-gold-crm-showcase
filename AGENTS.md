# Showcase editing rules

Read overview.md first. Stack: TypeScript helpers, Node 24+ built-in tests, Markdown/Mermaid documentation.

- Keep this an honest sanitized case study, not a simulated production CRM.
- Never copy private directories, Git history, operational comments, IDs, credentials, logs or contact records.
- Use only invented examples with example.com/example.org and reserved fictional numbers.
- New important files need a short purpose/dependency header.
- Keep production implementation claims tied to reviewed evidence; do not claim deployed state or security guarantees from source alone.
- Run npm test and review every proposed public file before publishing.
